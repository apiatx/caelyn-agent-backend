The proven defects are:

DEFECT 1 — CROSS-GENERATION ENTRY JOIN

build_confluence_snapshot() loads one Entry LKG generation and uses that exact entry_result to compute Elite Asset Rebound and Actionability.

But:

GET /api/watchlist/{watchlist_id}/alignment

independently calls get_all_entry_state_lkg() again at request time for:

entry.state

entry.score

entry.grade

Therefore a stale retained Confluence snapshot at generation T0 can be joined to newer Entry generation T1.

This was empirically reproduced:

retained Actionability:
WAIT_FOR_RETEST / 63.1

retained Trade Alignment:
81.9

live joined Entry:
BROKEN_STRUCTURE / 5 / AVOID

That combination never existed in one model generation.

DEFECT 2 — OPTIONS FINGERPRINT TRACKS THE WRONG SOURCE

_compute_source_fingerprint() currently fingerprints:

options_master_lkg_v1.json

But the Options Alignment result consumed by:

Trade Alignment

Actionability

and the compact row's options.pressure_state

comes from:

options_alignment.get_options_alignment_bulk()

→

data.options_theme_supplement.get_combined_ticker_data()

backed by the options Theme supplement cache/LKG.

The fingerprint currently does not directly track the canonical source that feeds Options Alignment.

DEFECT 3 — PRODUCTION PROCESS MODEL DOES NOT MATCH SINGLE-FLIGHT DESIGN

Development is single-process Uvicorn.

Production .replit deployment currently launches:

gunicorn -w 2 -k uvicorn.workers.UvicornWorker ...

_RETAINED and _RETAINED_LOCK are module-level process-local globals.

Therefore:

worker A and worker B have independent retained snapshots and independent locks.

Two workers can independently run ~129-second full Confluence builds and serve different snapshot generations.

DEFECT 4 — COLD START

No retained snapshot is warmed at startup.

First request to a retained-snapshot consumer can synchronously pay ~129 seconds.

DEFECT 5 — SHALLOW COPY MUTATION HAZARD

/api/alpha/confluence uses a shallow top-level copy of the retained snapshot.

Row dictionaries and nested objects remain shared with the canonical retained object.

A safe test proved mutating a row or nested signal_breakdown on the copied side mutates the retained cache itself.

DEFECT 6 — NO STALE-REASON DIAGNOSTICS

_retained_is_stale() returns only boolean.

Fingerprint deltas are available but discarded.
