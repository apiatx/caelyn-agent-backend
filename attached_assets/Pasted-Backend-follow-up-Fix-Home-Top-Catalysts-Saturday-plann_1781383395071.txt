Bug:
On Saturday/Sunday, `/api/home/top-catalysts` correctly selects the next-week planning window, but returns empty because next week’s snapshots have not been generated yet. The agent summary says “When Monday’s scheduler runs… cards will populate automatically,” but that defeats the whole purpose of Saturday planning.

Required behavior:
On Saturday/Sunday ET:

1. Determine next Monday–Friday planning window.
2. Check whether catalyst source data exists for that exact window.
3. If missing/stale, build or refresh the required next-week data immediately using existing cache/snapshot refresh functions.
4. Return populated next-week catalysts if the provider/source returns events.
5. Return empty only if the refresh succeeds and there truly are no catalysts for that next-week window.
