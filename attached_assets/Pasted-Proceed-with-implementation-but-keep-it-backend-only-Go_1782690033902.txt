* Select its binary market.
* Extract:

  * market_ticker
  * event_ticker
  * series_ticker

  * subtitle
  * question
  * yes_bid
  * yes_ask
  * last_price
  * probability
  * volume
  * volume_24h if available
  * open_interest
  * liquidity if available
  * close_time
  * expiration_time
  * status

Probability rule:

* Prefer midpoint of yes_bid/yes_ask if both exist.
* Else use last_price.
* Else use yes_bid/yes_ask fallback.
* Normalize to 0–1.
