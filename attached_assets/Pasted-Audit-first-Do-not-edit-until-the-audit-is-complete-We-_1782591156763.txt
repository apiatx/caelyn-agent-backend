We need to clean up the Prediction Markets / Polymarket / Prophetik backend logic without removing existing signal.

Goals:
1. Preserve the existing Polymarket/Kalshi fetching logic that is already finding useful market events.
2. Stop duplicate/conflicting Top Equity Signal cards for the same underlying event.
3. Remove or bypass any local hardcoded prediction-market industry/ticker catalog.
4. Use the app’s canonical backend sector/theme/sub-theme/ticker universe for all sector/theme/ticker mapping.
5. Resolve tickers user-first:
   - first: authenticated user’s watchlist symbols that belong to affected sectors/themes
   - second: canonical theme universe symbols
   - third: sector/theme only if no tickers are available
6. Add permanent tracked macro/market odds families:
   - Fed decision by date
   - recession by date
   - number of Fed cuts in 2026
   - Fed hikes in 2026
   - SPX / major index daily up/down markets
   - target price milestones for major watchlist/mega-cap names like NVDA, TSLA, AAPL, MSFT, GOOGL, AMD
   - tech earnings markets for companies on the user’s watchlist
   - AI/chips/data center/regulation/China export-control markets
   - geopolitics/oil/inflation/rates markets
7. Cache scan results and expose the latest normalized payload to the frontend. The scan target should be about every 30 minutes if the existing scheduler supports it. If not, implement the safest existing scheduler pattern already used in this codebase.
