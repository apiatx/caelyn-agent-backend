Stop. Sectors is still not working as intended.

Themes page is fixed, but Options Flow → Sectors is still unacceptable. Only ~2 sectors have any visible options data and ~90% of stocks/themes/sectors are missing. That is not a “wait longer” issue unless proven with diagnostics. The target is 99%+ optionable stock coverage across all sectors/themes, with every sector highlighted using bullish/bearish/neutral/no-flow state.

Critical clarification:
Do not equate “no unusual options flow” with “no options data.”

Expected behavior:

* Every optionable US ticker in the Sectors/Theme universe should have an options state row.
* If options chains were fetched successfully but there is no unusual activity, the row should still exist.
* It should show something like:

  * `options_data_available=true`
  * `options_signal="Neutral"` or `"No unusual flow"`
  * `options_flow_direction="neutral"`
  * call/put volume, OI, IV, put/call ratio if available
  * stale/LKG/retry fields if needed
* Only truly unsupported symbols should be excluded or marked unsupported.
* Pending should mean “not scanned yet,” not “scanned but no bullish/bearish flow.”

Right now the Sectors UI/API appears to be showing only tickers with detected bullish/bearish/unusual flow. That is wrong for coverage.

Do not continue feature work. Diagnose and fix Sectors coverage now.
