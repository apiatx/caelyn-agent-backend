PRIMARY BUG
The Social page `Refresh Snapshot` button is currently grayed out after hours and shows something like “next one in 10 hr”.

That means the backend/manual-refresh logic is incorrectly tying **manual refresh eligibility** to the **next automatic refresh window**.

That is wrong.

REQUIRED BEHAVIOR
Separate these two concepts completely:

1. Automatic refresh eligibility

* runs every 2 hours
* only between 8:00 AM and 8:00 PM America/Chicago
* zero automatic scans overnight

2. Manual refresh eligibility

* user may manually trigger refresh at any time, including after hours
* manual refresh should still be guarded by:

  * single-flight protection
  * cooldown / anti-spam
* manual refresh must NOT be blocked just because it is after 8 PM

AUDIT FIRST
Inspect the current implementation and identify exactly:

1. where the button-disabled metadata is coming from
2. whether `next_allowed_refresh_at` is incorrectly being reused for manual refresh
3. whether `manual_refresh_available` is being computed from the automatic schedule instead of manual cooldown state
4. what metadata the frontend currently receives that causes the button to gray out

IMPLEMENT
Fix the backend so it returns separate metadata for:

* automatic schedule
* manual refresh availability

Preferred metadata shape:

* `refresh_in_progress`
* `manual_refresh_available`
* `next_allowed_refresh_at`              # next automatic refresh window
* `next_manual_refresh_allowed_at`       # cooldown only
* `auto_refresh_window_open`
* `timezone`
* `manual_refresh_reason`                # optional human-readable reason when unavailable

Required logic:

* if after hours:

  * `auto_refresh_window_open = false`
  * automatic refresh blocked
  * BUT `manual_refresh_available = true` unless cooldown or single-flight says otherwise
* if refresh already running:

  * `manual_refresh_available = false`
  * `manual_refresh_reason = "refresh_in_progress"`
* if cooldown active:

  * `manual_refresh_available = false`
  * `manual_refresh_reason = "cooldown"`
* otherwise:

  * `manual_refresh_available = true`

IMPORTANT
Do NOT change the automatic quiet-hours policy.

Just stop using the overnight auto schedule to disable manual refresh.
