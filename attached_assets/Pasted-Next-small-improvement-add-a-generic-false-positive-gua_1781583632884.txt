Problem:
VISN slipped into ai_networking because a broad keyword like "network" matched an irrelevant company. We fixed VISN specifically, but other precise themes can have the same problem with broad words.

Goal:
Prevent weak single-keyword matches from qualifying tickers for precise themes unless there is stronger semantic proof.

Tasks:
1. Add a concept of weak_keywords vs strong_keywords for pure_subtheme themes.

Example:
ai_networking:
- weak_keywords: network, communications, connectivity
- strong_keywords: ethernet, switch, router, routing, optical networking, transceiver, data center networking, InfiniBand, network ASIC, DSP, packet processor

2. Rule:
For pure_subtheme themes, a ticker should not qualify from a weak keyword alone.
A weak keyword must be paired with at least one of:
- strong keyword match
- seed/manual_include
- theme-specific ETF/source
- allowed sector/industry + profile proof
- explicit manual override

3. Add/confirm irrelevant exclude_keywords for precise themes:
- ai_networking: marine, boat, electric boat, recreational vehicle
- power_cooling: generic utility-only names unless direct power/cooling/data-center infrastructure proof
- data_center_infrastructure: towers/telecom only if explicitly allowed
- photonics_lasers: generic optics words must not pull in unrelated medical/retail names
- robotics_automation: lab/genomics automation should be allowed only if ETF/source or explicit role supports it

For each precise theme, print any ticker whose only proof is a weak keyword.

- company_name
