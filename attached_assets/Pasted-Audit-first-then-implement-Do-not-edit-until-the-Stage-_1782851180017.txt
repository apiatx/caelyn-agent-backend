Phase 4 — Suggested signal logic:
Use simple, transparent heuristics first. Do not overfit.

Extension Risk:

* Overheated if price is far above 20D and 50D, for example >12–15% above 20D or >25–35% above 50D
* Extended if meaningfully above 50D but not extreme
* Pullback Buy Zone if price is near 20D/50D while MA stack is constructive
* Broken if below 50D and 200D
* Healthy if above key MAs but not stretched

Entry Zone:

* 20D Pullback if constructive trend and price near 20D
* 50D Pullback if constructive longer trend and price near 50D
* Breakout Watch if within a few percent of 20D/50D/52W high and range is tight
* Fresh Breakout if recently above recent high and not too extended
* Extended/Overheated if chase risk
* Broken if below support

Breakout Signal:

* Coiling if 20D range is tight and price is near trigger
* Near Trigger if close to recent high
* Fresh Breakout if price recently cleared recent high
* Confirmed Breakout if breakout is holding with volume confirmation
* Extended Breakout if breakout happened but price is now stretched
* Failed Breakout if price lost breakout level
* No Setup otherwise

Accum/Dist:

* Accumulation if more up-volume than down-volume days over 20D
* Heavy Accumulation if clustered up-volume days are well above average
* Distribution if repeated down-volume days
* Dry-Up if volume contracts during tight base/pullback
* Neutral otherwise

Squeeze:

* Tight/Coiling if 20D range and ATR% are low versus recent history and price is near trigger
* Expansion if volatility is expanding after compression
* Volatile if ATR%/range are high
* Normal otherwise

Momentum Trend:

* Accelerating if 20D ROC and 50D ROC are positive and improving
* Positive if trend is up
* Cooling if still positive but weakening
* Diverging if price near highs but momentum weakening
* Negative if ROC is negative
