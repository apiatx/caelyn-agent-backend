PART 5 — FORWARD P/E DERIVATION DESIGN
==================================================

Implement if data path exists safely.

Preferred method:

Forward P/E = current_price / forward_eps_ntm

Where forward_eps_ntm should be selected in this priority:

1. FMP Financial Estimates NTM / next fiscal year EPS estimate if directly available
2. Average or consensus EPS estimate for next fiscal year if available
3. Sum of next 4 quarters EPS estimates if quarterly estimates are available
4. Approximate from current EPS and EPS growth estimate only if explicitly labeled approximate

Use cached quote/current price:
- Prefer same price field already stored in fundamentals snapshot if available.
- Otherwise use cached quote/current price at scheduled refresh time.
- Do not fetch quote request-time just for modal/confluence.
