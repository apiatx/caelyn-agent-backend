PART 1 — PRESERVE REGULAR-SESSION QUOTE FIELDS AFTER HOURS

Current architecture to preserve:

* services/watchlist_quote_cache.py
* services/home_service.py::_batch_quotes()
* shared canonical per-symbol quote caches such as:

  * tradier:quote:sym:{SYM}
  * quote:lkg:{SYM}
  * home:wl_tradier_lkg:{SYM}
  * any existing durable quote/LKG store already used elsewhere
* services/watchlist_router.py::_enrich_store_with_quotes()
* the existing VolX and Vol/MC formulas

The required behavior is field-level last-known-good merging.

A newer quote must not erase a valid older field merely because the newer response is sparse.

Implement one shared canonical quote-merge policy and reuse it wherever Watchlist/Home canonical quote rows are updated.

Field rules:

* price:

  * Use the newest valid finite price greater than zero.
  * If the newest quote has no valid price, retain the last valid canonical price.
* change/change percentage:

  * Use the newest finite value.
  * Otherwise retain the last valid value.
* volume:

  * Treat null, missing, NaN, empty string, and zero as unavailable unless zero is explicitly proven to be a legitimate completed-session value.
  * Never overwrite a positive last-known regular-session volume with null/zero from an after-hours or closed-market response.
* average_volume:

  * Never overwrite a positive cached value with null/zero.
* relative_volume:

  * Recompute from the effective merged volume and average_volume.
  * Only use an upstream relative-volume value when the effective inputs are unavailable.
* dollar_volume:

  * Recompute from effective price × effective regular-session volume.
* vol_mc_ratio and vol_mc_pct:

  * Recompute from effective dollar volume and market cap.
* high/low/name:

  * Preserve the latest valid non-empty value.

Do not merge whole quote dictionaries with a simple dictionary replacement when the incoming quote may be sparse.

The canonical LKG must be updated with the fully merged row, not the raw provider row.

Example:

Existing canonical row:
{
price: 50,
volume: 1200000,
average_volume: 800000
}

New after-hours Tradier row:
{
price: 51,
volume: null,
average_volume: null
}

Required merged result:
{
price: 51,
volume: 1200000,
average_volume: 800000,
relative_volume: 1.5
}

Add provenance metadata without changing the existing display fields:

* market_session
* quote_is_stale
* price_is_stale
* volume_is_stale
* price_source
* volume_source
* quote_updated_at
* volume_updated_at or volume_market_date
* quote_fallback_reason

When regular-session volume is retained after hours, mark the volume as cached/LKG, but continue displaying it. Stale-but-valid is far better than blank pretending to be purity.

The retained volume should represent the most recent regular trading session. Do not mix extended-hours trade volume into the full regular-session volume unless an existing provider explicitly returns a correctly combined daily total.

1. Fresh valid canonical Tradier field.
2. Last-known-good regular-session field.
