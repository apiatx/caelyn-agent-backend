The frontend uses clean earnings endpoints such as week-clean/month-clean, not only the generic events endpoint.

Now apply the same watchlist source-of-truth fix to:
- next-week requests
- month-clean or whatever endpoint Month view calls
- any date-window variant of week-clean used when navigating forward

Hard rule:
For tab/route = earnings calendar AND scope=watchlist:
Never start from get_curated_earnings_range.
Never filter the All curated pool.
Always start from the user’s saved Watchlist symbols from Neon / watchlist_service and the user_earnings_service cache.
