Problem:

The post-fix report incorrectly stated that remaining not_scanned tickers like TSM, MSFT, and NVDA are “foreign-listed tickers outside the theme supplement universe.”

That is wrong.

MSFT and NVDA are obviously US-listed optionable tickers.
TSM is a US-listed ADR ticker with options and should be treated as scanner-eligible for this app.

The existing project convention is:

- Symbols with ":" prefixes are foreign / OTC / non-standard symbols.
  Examples:
  OTC:ATEYY
  AIM:VLX
  AMS:BESI
  ASX:...
- Simple symbols without ":" should not be classified as foreign/OTC just because the company domicile is foreign.
- Simple US-tradable ADR tickers like TSM should be treated as normal scanner-eligible symbols unless explicitly confirmed no-options.

Goal:

Fix the options not_scanned classification and queue logic so simple optionable watchlist tickers are not mislabeled as foreign/OTC or ignored because they are outside a theme supplement universe.

PART 3 — THEME SUPPLEMENT UNIVERSE FIX
==================================================

The report mentioned “outside the theme supplement universe.”

That may be true as a source explanation, but it must not be a final exclusion reason for options scanning.

Rule:

Theme supplement universe can help seed options coverage, but it cannot be the only source for options scanner eligibility.

Options scanner/backfill eligibility should include:

1. Current watchlist symbols
2. Portfolio underlyings
3. Known optionable simple symbols
4. Symbols with previous options LKG
5. Theme supplement symbols

If a simple watchlist ticker is missing from theme supplement universe, it should still be queued through watchlist/backfill coverage.

Do not let “outside theme supplement universe” become a permanent not_scanned state.
