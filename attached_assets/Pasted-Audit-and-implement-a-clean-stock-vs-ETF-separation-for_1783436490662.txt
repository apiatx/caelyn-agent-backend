Audit and implement a clean stock-vs-ETF separation for Options Flow → Net Flow, while preserving the existing dynamic options ingestion architecture.

There are THREE related requirements:

1. Audit suspicious exact-zero premium P/C values.
2. Separate ETF and stock universes semantically.
3. Make Sectors/Themes stock-breadth metrics exclude ETFs while retaining ETFs in the canonical options scan universe.

Do not edit until the full data flow is traced.

==================================================
PART A — AUDIT EXACT 0.00 PREMIUM P/C
==================================================

Observed problem:
Many ETFs and some stocks on Options Flow → Net Flow show premium P/C exactly 0.00.

This is suspicious because several ETFs show extreme call-heavy P/C during a broadly weak/crashing market.

Do not assume the values are wrong.
Do not fix this through formatting only.

Audit the actual data lineage.

Trace:
- raw Tradier chains
- expiration scope selected
- chain filtering
- premium calculation
- call premium aggregation
- put premium aggregation
- premium P/C derivation
- master screener cache
- supplement cache
- supplement LKG
- _build_ticker_node or equivalent Net Flow ticker builder
- frontend/API field returned

For at least:
- 5 ETFs currently showing 0.00 P/C
- 5 stocks currently showing 0.00 P/C

Output:
- symbol
- instrument type
- scan source: live/master/supplement/LKG
- scan status
- snapshot timestamp
- expiration_used
- dte_used
- number of expirations scanned
- call contracts considered
- put contracts considered
- call contracts rejected by filters, if tracked
- put contracts rejected by filters, if tracked
- raw call premium
- raw put premium
- raw unrounded P/C
- formatted displayed P/C
- exact formula used
- whether snapshot was complete/partial
- whether ratio 0 came from true put_premium === 0
- whether ratio was merely rounded to 0.00

Confirm this invariant:

If call_premium > 0:
raw_pcr = put_premium / call_premium

The P/C displayed by Net Flow must be derived from the same premium dollar fields displayed by Net Flow.

Do not use:
- volume P/C
- OI P/C
- pc_ratio from another signal engine
- a filtered numerator with an unfiltered denominator

unless explicitly labeled as a different metric.

Correct raw/effective ratio semantics:

A. call_premium > 0 and put_premium >= 0:
raw_pcr = put_premium / call_premium

B. call_premium === 0 and put_premium > 0:
raw_pcr is one-sided put flow / mathematically infinite
effective_pcr = 100 for bounded log/geometric calculations

C. put_premium === 0 and call_premium > 0:
raw_pcr = 0
effective_pcr = 0.01 for bounded log/geometric calculations

D. call_premium === 0 and put_premium === 0:
raw_pcr = null
effective_pcr = null

Do not overwrite raw premium values.

Expose, if needed:
- raw_premium_pcr
- effective_premium_pcr
- one_sided_flow: "call_only" | "put_only" | null

For normal finite ratios:
effective_premium_pcr = clamp(raw_premium_pcr, 0.01, 100)

The effective ratio is for:
- geometric breadth aggregation
- log deviation
- heatmap scoring

The raw ratio remains the factual underlying value.

Before claiming complete:
Explain exactly why the audited 0.00 examples were zero.

PART C — SPLIT STOCK AND ETF ANALYTICS
==================================================

The scanner universe must continue to include BOTH stocks and ETFs.

Do NOT remove ETFs from:
- canonical options required universe
- master/supplement scan eligibility merely because they are ETFs
- paced scan queue
- usable LKG persistence

Display/aggregation separation is not scan exclusion.

Required conceptual sets:

required_options_symbols =
    required_stock_symbols
    UNION
    required_etf_symbols

stock_symbols =
    required symbols where instrument_type == "stock"

etf_symbols =
    required symbols where instrument_type == "etf"

Preserve the existing dynamic theme-membership requirement:
Newly added stock OR ETF theme members must dynamically enter the canonical required options universe and existing paced scanner.

STOCK CATEGORY P/C
==================================================

For:
- Sectors
- Themes
- Sub-Themes

Primary breadth P/C must use UNIQUE VALID STOCK TICKERS ONLY.

Exclude ETFs.

For unique stock effective ratios r_i:

breadth_pcr =
    exp(
        average(log(r_i))
    )

Requirements:
- equal weight per unique stock
- dedupe symbol inside each aggregate
- exclude pending
- exclude deferred
- exclude no-options
- exclude missing/null snapshots
- do not substitute missing tickers with P/C 1
- ETFs do not contribute

A valid P/C row requires a usable completed snapshot.

For raw call-only flow:
effective ratio = 0.01

For raw put-only flow:
effective ratio = 100

For no premium on either side:
exclude as null

Retain secondary stock premium concentration metric:

stock_premium_weighted_pcr =
    sum(stock put premium)
    /
    sum(stock call premium)

Expose:
- breadth_pcr
- premium_weighted_pcr
- total_stock_tickers
- valid_stock_pcr_tickers
- missing_stock_pcr_tickers
- stock_pcr_coverage_pct

If existing field names are already consumed broadly:
Audit all callers before repurposing them.

Do not blindly change put_call_ratio semantics.
