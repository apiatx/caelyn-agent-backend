This is a surgical backend implementation for the existing "Sector Rotation" feature, which is being renamed to "Sectors" on the frontend. Do NOT do a broad refactor. Audit first, then implement carefully.

Goal:
Upgrade the current Sector Rotation backend into a true "Sectors" data + analysis surface that:
1. identifies the strongest outperforming sector(s) across multiple timeframes (1D, 7D, 30D+, and any already-supported longer ranges),
2. scans those winning sectors for the most relevant stocks right now,
3. tracks/display “anchor giants” for each winning sector (based on the existing Serenity strategy / strategy screener logic),
4. fixes the broken sector "agent analysis" flow,
5. persists the most recent generated sector analysis so it survives refresh until the user explicitly regenerates it.

Critical product intent:
- We care about where the real action is.
- Usually one sector stands out; sometimes multiple do.
- The page should surface both:
  - real momentum names in the winning sector(s)
  - real bottleneck / enabling / infrastructure names in that sector(s)
- “Anchor giants” should come from existing Serenity strategy logic if available. Reuse existing code/data/contracts where possible. Do not duplicate strategy logic if a reusable function already exists.
- The saved analysis must persist until manually regenerated by the user.
