```text

  reached approximately 18.7 seconds

  reached approximately 15–27 seconds
```

The Watchlist separately calls:

```http

```

The working hypothesis is that real-time FMP work is running:

* synchronously inside a browser-facing route
* on the shared event loop or shared request worker
* with overlapping scans
* with long provider timeouts or retries
* while holding shared resources
* through more than one earnings endpoint

Do not assume this hypothesis is correct.

Prove the actual architecture first.
