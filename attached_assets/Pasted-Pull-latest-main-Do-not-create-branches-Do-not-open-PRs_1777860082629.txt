Product direction:
The Thematic Screener should show useful small/mid-cap thematic candidates, supply-chain players, and high-volume movers. It should not be a historical performance table. It should not burn FMP with historical calls. It should not show ETFs/funds/inactive/junk securities.

Use the FMP Stock Screener as the main broad discovery source:
- one FMP screener call per mapped industry/filter
- many tickers returned per call
- never one FMP call per ticker for basic discovery
- never on normal page load
- only during scheduled/admin rebuilds
- governed by the existing FMP governor

Use these FMP screener fields:
- symbol
- companyName
- marketCap
- sector
- industry
- beta
- price
- lastAnnualDividend
- volume
- exchange
- exchangeShortName
- country
- isEtf
- isFund
- isActivelyTrading

Base filters for every Thematic FMP screener call:
- marketCapMoreThan=50000000
- marketCapLowerThan=10000000000
- volumeMoreThan=100000
- isEtf=false
- isFund=false
- isActivelyTrading=true
- limit=500 or conservative supported value
- includeAllShareClasses=false if supported

Do not use a broad all-market no-industry screen as the primary source.
