This is not acceptable. The requirement is to include every public company from the curated source maps, not just the top obvious names or summary/highlight names.

* Do NOT use Claude.

* Do NOT omit foreign tickers.

* Do NOT only include “top names.”
* Do NOT treat the earlier “must include names such as…” list as exhaustive. That was a minimum sanity check, not the full list.

Goal:
Make the backend static curated data exhaustive.

* master ranking tables

Deduping rule within the same anchor:

* Dedupe by canonical ticker only.
* If the same company appears in multiple layers for the same anchor, keep one row but merge:

  * layer roles
  * themes
  * evidence / notes
  * relationship reasons
  * source URLs if available
* Use the highest bottleneck score found for that anchor.
* Keep the most specific relationship/directness label.
* Preserve enough text so the detail drawer explains all relevant roles.

Across different anchors:

* Do NOT dedupe away rows.
* The same ticker must appear in every anchor tab where it belongs.
* Cross-anchor duplicates should be surfaced through overlap detection.

Acceptable exclusion reasons only:

* private company
* delisted / no longer public
* duplicate already merged under same anchor
* no public ticker was provided or reasonably inferable from the user’s source text

Ticker formatting:

* `ticker` / `bottleneck_ticker` should be the bare symbol where possible.
* `tradingview_symbol` should hold exchange prefix if needed.
* Do not drop a row because TradingView symbol is imperfect or uncertain.
* Keep foreign tickers visible:
  `.TW`, `.TWO`, `.T`, `.KS`, `.SZ`, `.SW`, `.PA`, `.AS`, `.VI`, `.DE`, `.MI`, `.HK`, `.HE`, `.TO`, `.V`, etc.
* Missing quote/live data should be `null` or `—`, not a reason to remove the row.
