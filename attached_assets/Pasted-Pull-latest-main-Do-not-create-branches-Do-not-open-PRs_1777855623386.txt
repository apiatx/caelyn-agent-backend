Goal:
Improve Thematic Screener hidden-gem quality using the FMP Stock Screener without increasing FMP usage on page load.

Current architecture to preserve:
- FMP screener calls only during scheduled/admin rebuilds.
- Page loads must be cache-only.
- One FMP screener call should return many tickers for one mapped industry/filter.

Main issue:
Thematic discovery is now dynamic, but too noisy. It admits irrelevant ultra-micro names, rights/warrants/units, low-volume junk, and weak adjacent-industry names. The Screener should find real $50M–$10B hidden gems/supply-chain players with liquidity and theme relevance.

Part 3 — Score theme relevance and quality

For each row add:
- theme_relevance_score
- source_confidence: high | medium | low
- quality_flags[]
- exclusion_reason if filtered
- liquidity_status
- dollar_volume
- volume_to_market_cap

Rules:
1. Core industry = high relevance.
2. Adjacent industry = medium relevance.
3. Weak adjacent industry = low relevance unless confirmed by ETF/LKG/social/options/watchlist/peer overlap.
4. Positive keyword match boosts relevance.
5. Negative keyword match penalizes relevance.
6. Multiple discovery sources boost confidence.
7. Micro/small/mid caps can receive hidden-gem boost, but micro-cap status alone must not dominate.
8. Mega/large names can remain visible as anchors, but should not dominate hidden_gem ranking.
