Option parser requirements:
Parse option contract metadata from symbol and/or description:
- underlying symbol
- expiration date
- strike price
- option_type: CALL or PUT
- contract_side/action: buy_to_open, sell_to_close, sell_to_open, buy_to_close
- contracts quantity
- premium price
- fees
- amount/proceeds
- contract_multiplier = 100
- OCC-style synthetic key:
  underlying + expiration + strike + option_type

Examples:
Symbol: "BWEN 07/17/2026 2.50 C"
Description: "CALL BROADWIND INC $2.5 EXP 07/17/26"

Should parse:
- underlying = BWEN
- expiration = 2026-07-17
- strike = 2.50
- option_type = CALL
- contracts = 18
- premium = 1.65
- contract_multiplier = 100
- total_cost = 18 * 1.65 * 100 + fees

Accounting rules for long options:
Buy to Open:
- contracts_open += contracts
- cost_basis += contracts * premium * 100 + fees
- avg_premium = cost_basis / (contracts_open * 100)

Sell to Close:
- contracts_sold = quantity
- proceeds = contracts_sold * premium * 100 - fees
- cost_basis_sold = avg_premium_before_sale * contracts_sold * 100
- realized_pnl = proceeds - cost_basis_sold
- realized_pnl_pct = realized_pnl / cost_basis_sold * 100
- contracts_open -= contracts_sold
- remaining_cost_basis -= cost_basis_sold
- avg_premium remains same under average-cost accounting
- if contracts_open > tolerance, status = partially_closed_open
- if contracts_open <= tolerance, status = fully_closed

Important:
Options quantity is contracts, not shares.
Always multiply premium by 100 unless contract_multiplier says otherwise.
