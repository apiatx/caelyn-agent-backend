Goal:
Create a monthly, cached, anchor-specific supply-chain research system that follows the Serenity bottleneck strategy:

Core Serenity strategy:

1. Start from a supercycle / secular demand anchor.
2. Work backward from the end customer.
3. Identify physical, capacity, regulatory, technical, geographic, or capital-intensive bottlenecks.
4. Map suppliers, enablers, scarce inputs, tooling, substrates, infrastructure, and public-market proxies.
5. Prefer unknown / undercovered bottlenecks over obvious crowded beneficiaries.
6. Score asymmetry: small/mid-cap public proxy, scarce capacity, pricing power, low substitutability, clean balance sheet, near-term catalysts.
7. Require evidence. No unsupported supplier claims.
8. Preserve the current Chain Reaction style: concise, direct, bottleneck-focused, research-grade.
