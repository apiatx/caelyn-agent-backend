3. Calculate OI delta
Add:
- oi_delta_5m_pct
- oi_delta_15m_pct
- oi_delta_1h_pct

Formula:
(current_open_interest - previous_open_interest) / previous_open_interest * 100

Guardrails:
- If previous OI is missing or zero, return null.
- Prefer existing USD-normalized OI if available.
- Otherwise use the same OI unit currently used in the page.
- Do not remove the existing raw OI field.

4. Calculate volume velocity
Add:
- volume_velocity_15m
- volume_velocity_1h
- vol_oi_ratio

If actual recent volume already exists from candles/trades, use it.

If only rolling 24h volume exists:
- Estimate recent volume by comparing current 24h volume against previous snapshot 24h volume.
- For 15m:
  current_24h_volume_delta = current_24h_volume - volume_24h_15m_ago
  expected_15m_volume = current_24h_volume / 96
  volume_velocity_15m = current_24h_volume_delta / expected_15m_volume

For 1h:
  current_24h_volume_delta = current_24h_volume - volume_24h_1h_ago
  expected_1h_volume = current_24h_volume / 24
  volume_velocity_1h = current_24h_volume_delta / expected_1h_volume

vol_oi_ratio:
24h volume notional / open interest notional

Guardrails:
- Return null if denominator is missing/zero.
- Clamp extreme nonsense values.
- Do not remove existing raw volume fields.
