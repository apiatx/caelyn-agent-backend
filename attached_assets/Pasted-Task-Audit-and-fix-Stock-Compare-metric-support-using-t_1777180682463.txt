Task: Audit and fix Stock Compare metric support using the actual FMP Starter plan access. Then expose a clean metric availability + normalized data contract for the frontend.

Context:
The Stock Compare section on the Fundamentals page currently has these chart metrics:

- Market Cap
- Revenue
- Revenue Growth
- Gross Profit
- Gross Margin
- Profit Margin
- EPS (Diluted)
- Operating Income
- Net Income
- EBITDA
- Free Cash Flow
- Total Debt
- P/S Ratio
- P/E Ratio
- Recent News

Some metrics are missing for certain tickers. I need backend to clearly support what FMP can provide, calculate safe fallbacks where possible, return null when not available, and never throw 500s for missing metrics.

Important:
FMP is the primary source. Use existing FMP client/cache utilities. Do not introduce a new data provider unless absolutely needed. SEC/Finnhub should not be used for this first cleanup unless already wired and needed as fallback.

Main backend goals:
1. Keep all valid numeric financial metrics.
2. Remove Recent News from chart metric behavior; news should be returned separately, not as a line-chart metric.
3. Add a few additional FMP-supported metrics that are useful in Stock Compare.
4. Add safe fallback calculations.
5. Add diagnostics so I can see which metrics are available per ticker.
6. Make the frontend response predictable and stable.

Metric source mapping:

1. price
Source: FMP quote
Fields to check:
- price
- previousClose if needed
Return number or null.

2. price_change_percent
Source: FMP quote or stock-price-change
Fields to check:
- changesPercentage
- changePercentage
- 1D
Normalize as percent number, not decimal.
Example: -1.82 means -1.82%, not -0.0182.

3. market_cap
Source priority:
- quote.marketCap
- profile.mktCap
- market-capitalization endpoint
Return number or null.

4. enterprise_value
Source:
- enterprise values endpoint
- key metrics if available
Return latest enterpriseValue or null.

5. revenue
Source:
- income statement revenue

6. revenue_growth
Source priority:
- income statement growth revenueGrowth
- fallback calculation from latest two annual revenue rows:
  (latestRevenue - priorRevenue) / priorRevenue
Return decimal.
Example: 0.084 means 8.4%.

7. gross_profit
Source:
- income statement grossProfit

8. gross_margin
Source priority:
- ratios grossProfitMargin / grossMargin
- fallback:
  grossProfit / revenue
Return decimal.

9. operating_income
Source:
- income statement operatingIncome

10. operating_margin
Fallback:
- operatingIncome / revenue
Return decimal.

11. net_income
Source:
- income statement netIncome

12. profit_margin
Source priority:
- ratios netProfitMargin / profitMargin
- fallback:
  netIncome / revenue
Return decimal.

13. eps_diluted
Source:
- income statement epsdiluted
- income statement epsDiluted
- income statement eps
Return number or null.

14. ebitda
Source:
- income statement ebitda
- key metrics if available
Return number or null.
Do not crash if missing.

15. free_cash_flow
Source priority:
- cash flow statement freeCashFlow
- fallback:
  operatingCashFlow - capitalExpenditure
Be careful: FMP capex is often negative. If capex is already negative, operatingCashFlow + capitalExpenditure may be equivalent. Inspect current project conventions and avoid double-counting.
Return number or null.

16. fcf_margin
Fallback:
- freeCashFlow / revenue
Return decimal.

17. total_debt
Source priority:
- balance sheet totalDebt
- fallback:
  shortTermDebt + longTermDebt
Return number or null.

18. debt_to_equity
Source priority:
- ratios debtEquityRatio / debtToEquity
- fallback:
  totalDebt / totalStockholdersEquity
Return decimal/ratio number or null.

19. current_ratio
Source:
- ratios currentRatio
- fallback:
  totalCurrentAssets / totalCurrentLiabilities
Return number or null.

20. ps_ratio
Source priority:
- ratios priceToSalesRatio
- key metrics priceToSalesRatio
- fallback:
  marketCap / revenue
Return number or null.

21. pe_ratio
Source priority:
- ratios priceEarningsRatio
- key metrics peRatio
- fallback:
  marketCap / netIncome
Only calculate fallback if netIncome > 0.
Return null if denominator <= 0.

22. ev_to_ebitda
Source priority:
- key metrics enterpriseValueOverEBITDA
- fallback:
  enterpriseValue / ebitda
Only calculate if ebitda > 0.
Return null otherwise.

23. roe
Source:
- ratios returnOnEquity / roe
Return decimal.

24. roa
Source:
- ratios returnOnAssets / roa
Return decimal.
