We need to add ETF holdings (constituents) support for the Sectors page popup without breaking anything and while respecting VERY LOW Finnhub API limits.

This applies to:
- Sector Performance → Sectors mode (XLK, XLE, XLF, etc.)
- Sector Performance → Themes mode (SMH, SOXX, QTUM, SRVR, BLOK, etc.)

----------------------------------
GOAL
----------------------------------

When the frontend opens the ETF popup, backend should return:
- Price
- Performance (1D, 7D, 30D, YTD, 1Y)
- ETF holdings (stocks inside the ETF)

----------------------------------
CRITICAL CONSTRAINT
----------------------------------

Finnhub API usage must be MINIMIZED.

DO NOT:
- Refresh holdings frequently
- Fetch holdings for all ETFs automatically
- Waste calls on page load

TTL = 7 DAYS (MINIMUM)

- 7–30 days → stale but still usable

- If stale (7–30 days):

- If API fails:
  → return stale data anyway

Store:

sector_etf_holdings:{symbol}

Cache must persist across restarts if possible.
