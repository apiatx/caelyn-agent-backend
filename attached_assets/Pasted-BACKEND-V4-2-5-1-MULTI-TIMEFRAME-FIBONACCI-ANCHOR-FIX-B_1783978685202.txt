BACKEND — V4.2.5.1 MULTI-TIMEFRAME FIBONACCI ANCHOR FIX

Backend only.

Do not touch frontend.
Do not change Confluence weights.
Do not hardcode ticker symbols.
Do not add provider calls.
Do not call LLMs.
Do not change options/catalyst/investment formulas.
Do not overclaim Fibonacci precision.

Goal:

The first Fib engine uses a single fixed anchor window:
- highest high in last 120 bars
- lowest low in 90 bars before that peak

That is too narrow.

120 bars means roughly 120 daily candles, about 6 trading months, so the current engine only captures one near/intermediate daily impulse. It will miss charts where the meaningful Fib structure is weekly, monthly, multi-year, or anchored from a major cycle low/high.

Build a multi-timeframe Fibonacci candidate engine that selects the most relevant active Fib context instead of relying on one fixed daily window.

==================================================
PART 2 — REPLACE SINGLE-ANCHOR FIB WITH MULTI-CANDIDATE FIB
==================================================

Modify fib_engine.py so it generates multiple Fib candidates.

Candidate types:

1. recent_daily_impulse
   window: 40–120 daily bars

2. intermediate_daily_impulse
   window: 120–252 daily bars

3. long_daily_impulse
   window: 252–756 daily bars if available

4. weekly_impulse
   resample daily bars to weekly bars if enough daily history exists
   windows: 52, 104, 156 weeks if available

5. monthly_impulse
   resample daily bars to monthly bars if enough history exists
   windows: 24, 36, 60 months if available

No provider calls.

Use only existing cached bars.

If longer-term bars are unavailable:
- do not calculate fake weekly/monthly Fibs
- expose FIB_LONG_TERM_DATA_UNAVAILABLE

==================================================
PART 3 — BETTER ANCHOR SELECTION
==================================================

Do not simply use highest high / lowest low blindly.

For each candidate, identify a relevant impulse using:

- pivot low before impulse
- pivot high after impulse
- swing magnitude
- recency
- anchor prominence
- whether the move represents a real impulse rather than noise
- whether current price is still related to that structure

Use existing pivot/swing helpers if available.

If not available, implement a simple deterministic pivot helper:
- local pivot high = high greater than N bars before/after
- local pivot low = low lower than N bars before/after
- use N=3 to 5 depending window

Candidate must include:

fib_timeframe
fib_window
fib_anchor_low
fib_anchor_high
fib_anchor_low_date
fib_anchor_high_date
fib_impulse_return_pct
fib_anchor_confidence

Anchor confidence should consider:

- size of impulse
- clean low-to-high structure
- recency
- pivot quality
- current price still within relevant range or near extension/retest
- overlap with known support/resistance if available

PART 6 — UPDATE ENTRY / EXIT INTEGRATION
==================================================

Entry/Exit should use the selected primary Fib context.

A Fib retest should help entry score only when:

- primary_fib_confidence is adequate
- current price is near the Fib level
- support has not failed
- no confirmed lower low
- level overlaps with prior high / shelf / MA / active support OR confidence is high enough

- support lost

- true chase extension with no reset

==================================================
PART 7 — UPDATE EXTENSION RESET LOGIC
==================================================

Use primary Fib context to distinguish:

TRUE_CHASE_EXTENSION
vs
CONSTRUCTIVE_RETEST_AFTER_EXTENSION

If a stock was extended but now:

- pulled back from recent high
- current price is near primary Fib 1.0 / retracement / prior high / MA support
- active support is intact or bounced_from_support
- no confirmed support loss
- no confirmed lower low
- invalidation level is definable

then allow:

extension_reset_state = CONSTRUCTIVE_RETEST_AFTER_EXTENSION

Do not classify as constructive if:
- price is still at local high
- no pullback
- no retest level
- no support
- no valid Fib or MA context
- entry risk/reward is still poor
