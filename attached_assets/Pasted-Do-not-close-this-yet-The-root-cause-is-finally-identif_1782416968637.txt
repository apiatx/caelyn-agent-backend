* if unsupported/foreign/OTC/no-options, mark it explicitly
* do not leave it invisible just because it lacks unusual flow

Required status model:
Every ticker in Sectors must have one of these explicit states:

1. `bullish_flow`

   * chain scanned successfully
   * bullish/unusual signal found

2. `bearish_flow`

   * chain scanned successfully
   * bearish/unusual signal found

3. `mixed_flow`

   * chain scanned successfully
   * mixed signals found

4. `neutral_no_unusual_flow`

   * chain scanned successfully
   * no unusual bullish/bearish flow found
   * this is the only valid true neutral flow state

5. `optionable_pending_chain`

   * expirations confirmed non-empty
   * chain not scanned yet, deferred, or not completed
   * counts as represented/optionable coverage, but not as true neutral flow

6. `confirmed_no_options`

   * expirations endpoint returned a real empty result
   * not a budget deferral
   * not a failed request

7. `unsupported_foreign_otc`

   * skipped by eligibility rules

8. `deferred_retry`

   * budget deferral / transient provider failure
   * must not poison no-options cache

9. `stale_lkg`

   * prior successful row exists but refresh pending

Critical correction:
Do not mark a ticker as true `neutral_no_unusual_flow` just because Stage-1 confirmed non-empty expirations.

Non-empty expirations only means:

* the ticker is optionable

It does not necessarily mean:

* the option chain was fetched successfully
* flow was analyzed
* no unusual flow was found

If only expirations are confirmed, write/return `optionable_pending_chain`, not true neutral.
