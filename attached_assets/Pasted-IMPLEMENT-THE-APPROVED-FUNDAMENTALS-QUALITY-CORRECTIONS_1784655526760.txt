==================================================

Replace the current EPS Growth source.

Keep the existing canonical output key:

EPS Growth

Do not rename the backend key and break existing frontend aliases.

Calculate true quarterly diluted EPS YoY from the existing eight quarterly income-statement rows:

latest-quarter diluted EPS
/
exact same fiscal quarter prior fiscal year diluted EPS
- 1

Use the diluted EPS field from the quarterly income statement.

Matching rules:

- Use exact fiscalYear + period matching.
- Do not use positional matching when fiscal metadata exists.
- Do not use the income-statement-growth endpoint value.
- Preserve the current 10-call architecture; the income-statement-growth call may continue supplying other legacy fields if anything else still needs it, but it must no longer determine EPS Growth.

Economic gates:

- Prior-year EPS > 0 and current EPS >= 0:
  calculate the percentage.
- Prior-year EPS <= 0 and current EPS > 0:
  do not calculate a misleading percentage.
  Store:
  _eps_growth_status = "turned_profitable"
- Prior-year EPS > 0 and current EPS < 0:
  store:
  _eps_growth_status = "turned_unprofitable"
- Both periods <= 0:
  store:
  _eps_growth_not_meaningful_reason = "negative_eps_basis"
- Missing exact prior fiscal-period match:
  store:
  _eps_growth_not_meaningful_reason = "missing_prior_fiscal_period"

## Net Debt / EBITDA

- Negative result is valid and means net cash.
