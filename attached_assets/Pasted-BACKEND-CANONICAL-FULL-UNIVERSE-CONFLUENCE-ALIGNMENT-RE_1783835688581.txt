PART 3 — FIX BUCKET SEMANTICS
==================================================

Populate:

caelyn_confluence_bucket

Allowed buckets:

ACTIONABLE
NEAR_ACTIONABLE
CONFLUENCE_AT_SUPPORT
WATCH_FOR_RESET
INVESTMENT_QUALITY
SPECULATIVE_TRADE
RISK_CONFLICT
NO_CLEAR_CONFLUENCE

Rules:

ACTIONABLE:
- actionability state is READY / actionable equivalent
- not too extended
- not lower-low confirmed
- not active support lost
- not BROKEN_SUPPORT_AVOID

NEAR_ACTIONABLE:
- WAIT_FOR_RETEST / WAIT_FOR_BREAKOUT / EARLY_WATCH / REVERSAL_WATCH
- setup developing
- not too extended
- not broken

CONFLUENCE_AT_SUPPORT:
- active support intact/testing/bounced
- confluence_at_support_score strong
- lower_low_confirmed false
- not too extended
- not broken

WATCH_FOR_RESET:
- actionability = TOO_EXTENDED
- OR entry_risk_reward_state = STRONG_ASSET_EXTENDED_WAIT
- OR extension_state = EXTREME_EXTENSION / VERTICAL / CROWDED_MOVE

Important:

TOO_EXTENDED is not RISK_CONFLICT.
Extended means timing/chase risk, not chart broken.

RISK_CONFLICT:
Only use for true risk/breakdown/conflict:

- lower_low_confirmed = true
- active_support_status = lost_confirmed
- entry_state = SUPPORT_LOST / FAILED_BREAKOUT / LOWER_LOW_CONFIRMED
- actionability = AVOID
- entry_risk_reward_state = BROKEN_SUPPORT_AVOID
- material bearish catalyst conflict

Do not bucket a name as RISK_CONFLICT just because it is extended.

INVESTMENT_QUALITY:
Use only when this row is primarily a high-quality investment name but not currently actionable.
Do not force all strong investments into this bucket if they belong in WATCH_FOR_RESET or CONFLUENCE_AT_SUPPORT.

SPECULATIVE_TRADE:
Trade/catalyst/options/theme confluence exists, but Investment Alignment is weak or unavailable.

NO_CLEAR_CONFLUENCE:
Everything else.

Caps:

If WATCH_FOR_RESET:
cap caelyn_confluence_score at 60 unless explicitly justified.

If RISK_CONFLICT:
cap caelyn_confluence_score at 45 unless shown only inside Risk.

If CONFLUENCE_AT_SUPPORT:
allow score to rank well if support is intact and trade/catalyst alignment exists.
