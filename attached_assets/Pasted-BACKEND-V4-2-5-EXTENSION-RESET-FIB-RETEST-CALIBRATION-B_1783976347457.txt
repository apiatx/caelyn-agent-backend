BACKEND — V4.2.5 EXTENSION RESET + FIB RETEST CALIBRATION

Backend only.

Do not touch frontend.
Do not change Confluence weights.
Do not hardcode ticker symbols.
Do not add provider calls.
Do not call LLMs.
Do not change options/catalyst/investment formulas.
Do not loosen all extension rules blindly.

Goal:

The current engine is still too binary on over-extension.

It correctly blocks true vertical chase entries, but it can incorrectly block stocks that were extended, then pulled back into a valid retest / prior-high / moving-average / Fibonacci support level.

We need to distinguish:

1. TRUE_CHASE_EXTENSION
   - price shot straight up
   - no meaningful pullback
   - sitting at or near local high
   - no defined support/retest level
   - poor R/R

2. CONSTRUCTIVE_RETEST_AFTER_EXTENSION
   - stock had a strong impulse move
   - has now pulled back or consolidated
   - is retesting prior resistance / breakout shelf / Fib 1.0 / moving average / active support
   - support has not failed
   - invalidation is definable

3. HEALTHY_TREND_PULLBACK
   - slow or stair-step climb
   - regular pullbacks along the way
   - currently pulling into 20/30/50/200DMA or prior support
   - not a vertical chase

This must be generic and repeatable.

PART 2 — ADD EXTENSION RESET CLASSIFICATION
==================================================

Add a new derived field:

extension_reset_state

Allowed values:

TRUE_CHASE_EXTENSION
EXTENDED_NO_RESET
CONSTRUCTIVE_RETEST_AFTER_EXTENSION
HEALTHY_TREND_PULLBACK
HIGH_BASE_RESET
EARLY_RESET_FORMING
NOT_EXTENDED
UNKNOWN

Add:

extension_reset_score
extension_reset_reason_codes

Rules:

TRUE_CHASE_EXTENSION:
- extension_state in {EXTREME_EXTENSION, EXTENDED}
- extension_quality = CHASE
- current price is near recent high
- drawdown from recent high is shallow
- no support/retest level nearby
- entry_exit_points very weak
- no moving-average/fib/prior-high retest

CONSTRUCTIVE_RETEST_AFTER_EXTENSION:
- extension_state in {EXTREME_EXTENSION, EXTENDED}
- prior impulse move exists
- current price has pulled back from recent high
- active support is intact OR bounced_from_support OR above_support
- current price is near one or more valid retest levels:
  prior high
  breakout shelf
  reclaim level
  active support
  20DMA
  30DMA
  50DMA
  200DMA
  Fib 1.0
  Fib 0.786 / 0.618 / 0.5 / 0.382
- no confirmed support loss
- no confirmed lower low

HEALTHY_TREND_PULLBACK:
- extension_state can be MODERATELY_EXTENDED, EXTENDED, or HEALTHY
- price trend is stair-step / not vertical if detectable
- pullbacks have occurred along the way
- current price is near 20/30/50/200DMA or prior support
- support intact
- no major breakdown

HIGH_BASE_RESET:
- high-base / shelf / VCP / consolidation pattern
- near highs but not at blowoff high
- range contraction or shelf support if available
- not support_lost
- no chase_bad

Do not classify as TRUE_CHASE_EXTENSION just because price is far above a long-term MA.
A stock can remain extended above the 200DMA while still presenting a valid pullback entry.

Anchor selection rules:

Prefer recent major impulse:
- swing low before the strongest recent advance
- swing high at recent impulse peak
- use pivot highs/lows already available if possible
- otherwise derive from recent 60–120 daily bars

Do not fabricate Fib levels if bars are unavailable.

If multiple anchors are possible:
- prefer the impulse that aligns with current price action and recent breakout/retest
- expose FIB_ANCHOR_LOW_CONFIDENCE if anchor confidence is low

Fib retest detection:

Current price is near a Fib level if within:
- 2.5% for large/liquid stocks
- 4.0% for volatile small caps
- or within 0.5 ATR if ATR is available

Important:
Fib 1.0 is valid as a prior impulse high / prior resistance retest.
This is especially important for ABCL and ALGM-type setups.
