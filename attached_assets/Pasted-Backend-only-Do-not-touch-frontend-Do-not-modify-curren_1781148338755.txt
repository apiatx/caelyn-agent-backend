Goal:
Add Saved Screens for Screener Hub using the rows and metadata that already exist.

This feature should save the current visible Screener Hub results as a dated snapshot, let the user reopen saved screens later, and provide insights across saved screens.

Important:
Do not re-run the screener when saving or opening a saved screen.
Do not fetch fresh provider data when saving or opening a saved screen.
Do not call FMP or Tradier live for this feature.
Use existing cached quote data only where needed for insights.
Reuse existing auth/user separation patterns from Watchlist/Portfolio if available.

Part 2 — Endpoints

Add endpoints:

POST /api/screener-hub/saved-screens

Body:
{
"name": optional string,
"tab": "thematic" | "social" | "bottlenecks" | "watchlist_portfolio" | "fundamentals",
"theme_key": optional string,
"theme_label": optional string,
"filters": object,
"query_params": object,
"rows": array of current visible rows,
"metadata": object optional
}

Behavior:

* Save exactly the rows provided by the frontend/current visible table.
* Do not re-run the screener.
* Do not call providers.
* Normalize key fields into columns and preserve full original row_json.
* Include current metadata such as universe_built_at, served_at, universe_age_hours, universe_db_source, quote_cache_status, low_metadata_coverage, coverage metrics, applied filters, and theme RS metadata if provided.
* If name is missing, generate:
  "{Theme or Tab} — {MMM D, YYYY}"

GET /api/screener-hub/saved-screens

Returns saved screens list:

* id
* name
* tab
* theme_key
* theme_label
* row_count
* created_at
* updated_at
* filters_json summary
* metadata_json summary
* top_symbols_preview, first 5–10 symbols from saved rows

GET /api/screener-hub/saved-screens/{id}

Returns:

* saved screen metadata
* saved rows
* no provider calls

DELETE /api/screener-hub/saved-screens/{id}

Deletes saved screen and rows.

Important:
Register /saved-screens/insights before /saved-screens/{id} so “insights” is not treated as an id.

GET /api/screener-hub/saved-screens/insights

Part 3 — Insight logic

Recurring ticker:

* symbol appears in 2+ saved screens in the lookback window

Week-over-week ticker:

* symbol appears in saved screens across at least 2 different calendar weeks

Newly appearing:

* symbol appears in the most recent saved screen but did not appear in the prior saved screen or prior N saved screens

Disappeared:

* symbol appeared in the previous saved screen but not the most recent saved screen

Themes by frequency:

* count saved screens by theme_key/theme_label

Emerging themes:

* theme appears more frequently in the most recent portion of the lookback window than earlier

Performance since first saved:

* first_price = first saved price_at_save for symbol
* latest_price = latest existing cached quote price if safely readable from current quote cache
* fallback latest_price = latest saved price_at_save
* performance_pct = ((latest_price - first_price) / first_price) * 100
* if price unavailable, performance_pct = null

Do not call FMP.
Do not call Tradier live.
Do not refresh quotes.
Use only existing quote cache if already available and safe.
