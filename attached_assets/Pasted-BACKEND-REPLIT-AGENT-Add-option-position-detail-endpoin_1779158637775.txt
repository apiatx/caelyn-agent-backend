BACKEND REPLIT AGENT — Add option-position detail endpoint for Portfolio Dashboard option popup

We need a backend endpoint for the Portfolio Dashboard Open Options section popup.

Current frontend already shows Open Options positions in the Dashboard:
- BWEN
- FCEL
- GSIT
- SKYT
- VIVO

User wants each asset/underlying in the Options section to be clickable and open a TradingView-style popup, similar to the Core/Open Positions section popup.

The popup should show:
1. Underlying TradingView chart data/symbol metadata
2. Full open option position details
3. Existing portfolio-scoped options signal data
4. Existing portfolio-scoped options risk score/custom risk logic
5. Tradier-derived mark/quote fields already being used for open options valuation

Important:
Use existing backend logic.
Do not rebuild options scoring.
Do not duplicate Tradier calls if existing portfolio terminal/portfolio options service already has the data cached.
Do not call market-wide Options Flow logic for all tickers.
Do not affect the global Options Flow page.
Do not hardcode BWEN/FCEL/GSIT/SKYT/VIVO.
Only return popup data for underlyings/contracts currently present in the user’s open option positions.

Audit first:
1. Locate backend logic currently used by Portfolio Terminal Options section:

Goal:
Add a focused backend endpoint for option-position popup detail.

Preferred endpoint:
GET /api/portfolio/options-position-detail/{underlying}

Alternative:
GET /api/portfolio/options-position-detail?underlying=BWEN

Required behavior:
1. Load current user’s open option positions from the existing option positions store.
2. Filter to matching underlying.
3. If no open option position exists for that underlying, return 404 or structured empty result.
4. Pull/enrich the same portfolio-scoped options signal/risk data used by Portfolio Terminal, but only for this underlying.
5. Return contract-level option position details and underlying-level signal/risk data.
6. Use existing Tradier option mark quote cache where possible.
7. Do not scan the full market or all portfolio holdings if not necessary.
