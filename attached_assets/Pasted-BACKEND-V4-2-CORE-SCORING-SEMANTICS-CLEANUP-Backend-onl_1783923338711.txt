PART 2 — THEME ALIGNMENT — 15 POINTS
==================================================

Theme Alignment should answer:

“Is this ticker aligned with a leading or emerging investible theme?”

It should not require the single #1 theme. Top 5–6 tradable themes should still score well.

Target formula:

Theme Alignment raw score =
40% Theme Relative Strength
25% Theme Stage
25% Theme Performance Acceleration
10% Theme Policy Alignment

Then:

theme_alignment_points = theme_alignment_raw_score / 100 * 15

Inputs should come from existing Themes page / Theme Rotation / theme resolver data only.

Theme Relative Strength:
- Top 1–2 theme = excellent
- Top 3–6 theme = strong
- Top 7–10 theme = decent
- Neutral = low/moderate
- Lagging = weak

Theme Performance Acceleration should consider existing theme:
- 30D performance
- 7D performance
- 1D performance
- whether theme performance is improving or fading

Theme Policy handling:

- Ongoing/stale/structural policy support boosts Theme Alignment only.
- Fresh/recent/material government or presidential announcement can also count as Catalyst.
- Remove standalone theme_policy_bonus_points from score.
- Keep theme_policy_bonus_points only as debug/display if needed, but it must not add extra points beyond the Theme/Catalyst logic.
