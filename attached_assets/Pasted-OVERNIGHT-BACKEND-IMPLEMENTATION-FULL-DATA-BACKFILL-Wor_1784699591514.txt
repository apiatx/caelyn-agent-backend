PHASE 8 — CALCULATE HISTORICAL REACTIONS

Use ordered trading-session rows, not calendar-day offsets.

AMC:

- baseline = earnings-date regular-session close
- first reaction session = next trading session
- opening gap = next-session open versus baseline
- 1D = next-session close versus baseline
- 3D = third subsequent trading-session close versus baseline
- 5D = fifth subsequent trading-session close versus baseline

BMO:

- baseline = previous trading-session close
- first reaction session = report-date trading session
- opening gap = report-date open versus baseline
- 1D = report-date close versus baseline
- 3D = third applicable reaction-session close versus baseline
- 5D = fifth applicable reaction-session close versus baseline

For unknown timing:

- do not claim a precise BMO/AMC reaction
- use a clearly labeled close-to-close approximation only when methodologically safe
- calculation_method = unknown_timing_close_to_close
- do not calculate an opening gap if the baseline is ambiguous
- exclude unknown-timing approximations from primary BMO/AMC summary statistics

Return for each event:

- baseline_date
- baseline_close
- first_reaction_session
- opening_gap_pct
- reaction_1d_pct
- reaction_3d_pct
- reaction_5d_pct
- max_upside_5d_pct
- max_drawdown_5d_pct
- sessions_used
- calculation_method
- calculation_confidence
- reactions_final
- bars_source

max_upside_5d_pct:

- highest intraday high during the five-session reaction window versus baseline

max_drawdown_5d_pct:

- lowest intraday low during the window versus baseline
- downside must be negative
- return 0.0 when price never traded below baseline
- never return a positive drawdown
