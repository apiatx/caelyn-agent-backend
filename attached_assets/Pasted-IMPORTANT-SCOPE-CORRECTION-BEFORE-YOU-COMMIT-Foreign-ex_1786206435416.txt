IMPORTANT SCOPE CORRECTION BEFORE YOU COMMIT

Foreign-exchange securities are NOT supported provider securities in this app.

The user only has provider coverage for:

1. normal U.S.-listed securities
2. OTC securities through FMP

True foreign-exchange listings must NOT participate in ANY market-data,
fundamentals, financial, earnings, quote, refresh, scheduler, fallback, or
provider-fetch path.

============================================================
THE ONLY THREE SECURITY CLASSES
============================================================

CLASS A — NORMAL U.S.

Example:
    NVDA

Allowed:

    Tradier realtime quote path
    existing U.S. FMP fundamentals path
    existing U.S. earnings path
    existing supported history/technical paths

Do not change existing behavior.

CLASS B — OTC

Example:
    OTC:BESIY

Allowed:

    FMP realtime quote
    FMP weekly fundamentals / financials
    FMP earnings monitoring
    canonical Watchlist key remains OTC:BESIY

Bare:

    BESIY

exists ONLY at the FMP provider boundary.

Never send OTC to Tradier.

CLASS C — TRUE FOREIGN

Examples:

    TSX:FLT
    ASX:EQR
    FRA:APR
    TYO:6315

Allowed:

    Watchlist membership
    frontend display when Show Foreign is enabled

NOT allowed:

    Tradier quotes
    FMP quotes
    Public fallback
    Twelve Data fallback
    weekly FMP fundamentals
    earnings calendar
    earnings monitor
    earnings fallback lookup
    realtime quote cache population
    scheduled refresh
    background refresh
    provider fallback
    normalization to bare ticker

No provider call should ever result from these symbols.

============================================================
REALTIME QUOTE ENDPOINT
============================================================

For:

    /api/market/realtime-quotes

it is acceptable for a requested foreign symbol such as TSX:FLT to appear in
the RESPONSE as an explicit unsupported/error row if that is the established
endpoint contract.

For example conceptually:

    symbol: TSX:FLT
    source: none
    error: unsupported_foreign_listing
    is_realtime: false
    is_stale: true

That is NOT the same as including it in the provider pipeline.

The critical requirements are:

    Tradier call count for TSX:FLT = 0
    FMP call count for TSX:FLT = 0
    Public call count for TSX:FLT = 0
    TwelveData call count for TSX:FLT = 0

Do NOT treat the presence of an explicit error object in the response as
provider eligibility.

However, if the endpoint currently reports generic "invalid_symbol", consider
whether the existing contract can cleanly preserve that without changing
response semantics.

Do not broaden scope just to rename the error.

Do not turn all colon symbols into bare provider symbols.
