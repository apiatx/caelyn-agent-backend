Important clarification:
The TA Screener is for asset discovery. Do not turn it into a TA scan over a hardcoded thematic watchlist.

ThematicContextProvider should guide discovery, not replace discovery.

Audit/implement a Dynamic Thematic Universe Builder that converts active/emerging themes into ticker candidates using dynamic sources, not just hardcoded tickers.

Requirements:

1. Keep Finviz broad discovery.
For TA Screener, continue running the existing broad Finviz technical screens. Do not restrict Finviz to preselected theme tickers.

2. Add a theme-priority discovery lane.
For each active/emerging theme from ThematicContextProvider, build candidate tickers dynamically from:
- ETF/proxy holdings where available through Finnhub or existing cached ETF data
- FMP stock screener by sector/industry filters
- FMP company peers from a small set of theme proxy/anchor names
- FMP/search stock news ticker extraction using theme keywords
- X/Grok consensus tickers if cached
- existing broad Finviz candidates that map to the theme

3. Theme registry should define discovery rules, not final tickers.
Each theme may have:
- proxy_etfs
- keywords
- sectors
- industries
- optional seed anchors for peer expansion
But seed anchors are only for expansion, not the final universe.
