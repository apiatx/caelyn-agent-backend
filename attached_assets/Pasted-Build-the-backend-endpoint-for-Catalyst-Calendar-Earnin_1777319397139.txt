Build the backend endpoint for Catalyst Calendar > Earnings Dates > This Week.

Frontend context:
The frontend already has:
- This Week => earningsMode = "thisweek"
- Day => earningsMode = "upcoming"
- Recent => earningsMode = "recent"

This Week currently renders a blank placeholder.
Day and Recent are working. Do not touch them.

Goal:
Create a simple curated weekly earnings board endpoint modeled after a weekly earnings watchlist UI.

Endpoint:
GET /api/catalysts/earnings/week-clean

Query params:
- week_start=YYYY-MM-DD optional
- weekStart=YYYY-MM-DD optional alias
- week_end=YYYY-MM-DD optional
- weekEnd=YYYY-MM-DD optional alias
- limit_per_session default 8, max 15
- max_total default 60, max 100
- search optional
- scope=all|watchlist|portfolio optional

Default:
- current week Monday through Friday
- one week only

Hard rules:
- FMP only
- no Finnhub
- no Polymarket
- no beat odds
- no AI calls
- no 30-day preload
- no changes to Day, Recent, popup, Home, Sectors, Macro

Response shape:
{
  "asOf": "ISO timestamp",
  "source": "fmp",
  "weekStart": "YYYY-MM-DD",
  "weekEnd": "YYYY-MM-DD",
  "days": [
    {
      "date": "YYYY-MM-DD",
      "label": "Mon, Apr 27",
      "weekday": "Monday",
      "count": 0,
      "preMarket": [],
      "afterHours": [],
      "duringMarket": [],
      "unknown": [],
      "entries": []
    }
  ],
  "topEvents": [],
  "status": "ok" | "partial" | "error",
  "errors": []
}

Each event:
{
  "id": "string",
  "date": "YYYY-MM-DD",
  "session": "preMarket" | "afterHours" | "duringMarket" | "unknown",
  "symbol": "string",
  "companyName": "string | null",
  "logo": "string | null",
  "image": "string | null",
  "price": number | null,
  "priceChangePct": number | null,
  "marketCap": number | null,
  "marketCapBucket": "mega" | "large" | "mid" | "small" | "micro" | "unknown",
  "sector": "string | null",
  "industry": "string | null",
  "time": "string | null",
  "period": "string | null",
  "epsEstimated": number | null,
  "revenueEstimated": number | null,
  "themeTags": ["string"],
  "isThemeAnchor": boolean,
  "isBottleneck": boolean,
  "importanceScore": number,
  "scoreBreakdown": {
    "marketCap": number,
    "theme": number,
    "estimateAvailability": number,
    "priceMomentum": number,
    "watchlistPortfolio": number
  },
  "source": "fmp",
  "raw": object
}

symbol + date + session

If a symbol belongs to multiple themes:
- attach all themeTags
- increase score, but cap total theme score at 40
- do not duplicate the card
