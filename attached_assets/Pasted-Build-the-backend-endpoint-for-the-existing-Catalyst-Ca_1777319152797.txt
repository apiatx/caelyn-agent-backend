Goal:
Create a new backend endpoint for the This Week toggle only.

Endpoint:
GET /api/catalysts/earnings/week-clean

Query params:
- week_start=YYYY-MM-DD optional
- weekStart=YYYY-MM-DD optional alias
- week_end=YYYY-MM-DD optional
- weekEnd=YYYY-MM-DD optional alias
- scope=all|watchlist|portfolio optional, default all
- search optional
- limit_per_session optional, default 10, max 20
- max_total optional, default 80, max 150
- include_theme_scoring optional, default true

Default behavior:
- If week_start not provided, use current week Monday.
- weekEnd should be Friday by default.
- Return Monday-Friday earnings grouped by day and session.
- Do not fetch more than one week.
- Do not preload 30 days.
- Do not call AI APIs.

Use FMP only:
- No Finnhub.
- No Polymarket.
- No beat odds.
- No prediction market data.
- No Grok / Claude / OpenAI / Perplexity / Gemini calls.

FMP safety rules:
This endpoint must not repeat the prior FMP overload problem.

Hard limits:
- One week only.
- No 30-day or 60-day fetch.
- No all-universe profile enrichment.
- No FMP calls at import/startup.
- No unbounded asyncio.gather.
- No new AsyncClient per symbol.
- No polling/retry storm.
- No route should be capable of breaking Home/Sectors/Macro if FMP 429s.

Fetching:
- Use existing safe FMP earnings calendar helper if possible.
- Fetch only weekStart through weekEnd.
- If chunking is needed, chunks must be sequential, not parallel.
- Max earnings-calendar FMP calls: 1-2 per request.

Enrichment:
This Week is curated, so enrichment should happen only after reducing candidates.

Process:
1. Fetch all FMP earnings for the week.
2. Normalize basic events.
3. Apply rough pre-score using only fields already in the earnings calendar:
   - symbol
   - EPS estimate availability
   - revenue estimate availability
   - time/session
   - known theme baskets
4. Select likely candidates for enrichment.
5. Enrich only top candidates, not every tiny/OTC symbol.

Enrichment rules:
- company/profile cache TTL: 24h+
- quote/price cache TTL: 15-60 min
- marketCap cache TTL: 24h
- max live profile/quote/marketCap calls should be capped.
- suggested max_live_enrich default: 40 total symbols for the week
- concurrency max: 2
- one shared httpx.AsyncClient per request
- timeout max 3 seconds per FMP call
- if FMP returns 429, stop enrichment and return partial data
- earnings route-specific 429 circuit breaker should apply
