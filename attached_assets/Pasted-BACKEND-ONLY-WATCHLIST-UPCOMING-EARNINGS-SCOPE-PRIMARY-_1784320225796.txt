PART 2 — FIX EARNINGS CONTRACT
==================================================

Preferred endpoint:

POST /api/watchlist/earnings/by-symbols

Body:
{
  "symbols": ["AAPL", "MSFT", "NVDA"]
}

Alternative acceptable endpoint:

GET /api/watchlist/earnings?symbols=AAPL,MSFT,NVDA

Requirements:

- Accept explicit symbols from frontend.
- Normalize uppercase.
- Deduplicate.
- Return upcoming earnings only for requested symbols.
- Never return earnings for unrequested symbols.
- Use existing cached earnings/FMP calendar path.
- Do not add one FMP request per symbol at request time.
- If cache is missing for a requested symbol, return it in missing_symbols.
- If no earnings exist for requested symbols, return empty events calmly.
- Do not return Strong Bases events unless Strong Bases symbols were requested.

Response:

{
  "symbols_requested": [...],
  "events": [...],
  "missing_symbols": [...],
  "source": "cached_earnings",
  "last_updated": "...",
  "stale": false
}

Each event:

- symbol or ticker
- company
- earnings_date
- time
- eps_estimate
- revenue_estimate
- previous_eps if available
- source
- last_updated
