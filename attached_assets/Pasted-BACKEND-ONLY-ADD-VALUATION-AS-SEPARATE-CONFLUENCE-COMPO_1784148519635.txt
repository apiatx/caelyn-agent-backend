PART 7 — MISSING DATA BEHAVIOR
==================================================

Do not punish missing data too harshly.

Rules:

- If one of P/E, P/S, Forward P/E is missing, average available scores and apply a small confidence haircut.
- If two are missing, use available score with larger confidence haircut.
- If all three are missing, valuation points = 0 and coverage flag = VALUATION_UNAVAILABLE.
- Negative P/E should be treated as unavailable/low-confidence, not as attractive.
- P/S can carry more weight when P/E is unavailable due unprofitability.
