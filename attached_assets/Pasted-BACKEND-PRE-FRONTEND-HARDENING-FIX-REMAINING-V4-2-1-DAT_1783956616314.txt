PART 1 — CATALYST LKG COLD-START FIX
==================================================

Problem:

Catalyst V4.2.1 code is correct, but after server restart the retained snapshot can rebuild while catalyst in-memory LKG is cold. In the final report, catalyst detection dropped to 2 tickers even though previous warm state had ~90+ catalyst signals.

This makes Confluence scores artificially low after restart.

Required behavior:

Confluence snapshot rebuild must not lose catalyst intelligence just because the background catalyst scanner has not warmed yet.

Implement durable catalyst LKG fallback:

1. Identify the current canonical catalyst source used by:
   - catalyst_alignment.py
   - watchlist RSS catalyst alignment
   - scheduled catalyst fields
   - nested catalyst dicts
   - primary_catalyst / catalyst_v2_primary_event / catalyst_events

2. Find whether there is already a persisted catalyst LKG file or Neon snapshot.
   Prefer existing storage. Do not invent a new unrelated store if one exists.

3. On startup and/or retained snapshot rebuild:
   - If in-memory catalyst map is warm, use it.
   - If in-memory catalyst map is empty/cold, load the last persisted catalyst LKG.
   - If both are unavailable, mark catalyst_status="unavailable_cold_lkg" and keep score 0.
   - Do not rebuild a retained snapshot that silently downgrades all catalyst rows without a reason code.

4. Add reason/status fields:
   - catalyst_lkg_source: "memory" | "disk_lkg" | "neon_lkg" | "unavailable"
   - catalyst_lkg_warm: true/false
   - catalyst_lkg_age_minutes
   - catalyst_lkg_fallback_used: true/false
   - CATALYST_LKG_COLD_FALLBACK_USED reason code when fallback is used
   - CATALYST_LKG_UNAVAILABLE_COLD_START when no fallback exists

5. Add empty-overwrite guard:
   - If current catalyst scan returns near-empty data due to cold start, do not overwrite a richer previous LKG.
   - Treat a sudden collapse from ~90+ catalyst rows to <10 as suspicious unless explicitly caused by expiry.
   - Keep previous LKG until the new scan is complete and valid.

6. Validation:
   Restart server.
   Immediately trigger or read retained confluence snapshot.
   Confirm catalyst count does not collapse to 2.
   Confirm catalyst count after restart is either:
   - same as previous persisted LKG, or
   - explicitly marked unavailable_cold_lkg without silently suppressing.

Return counts:
   before restart catalyst rows
   after restart immediate catalyst rows
   after warmup catalyst rows
   catalyst_lkg_source distribution
   fallback_used count
