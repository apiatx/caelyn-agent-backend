Implement Phase 1.5:

1. Promote `_WL_INFLIGHT_SYMS` into a shared/global options-symbol in-flight guard.

   * Suggested names:

     * `_OPTIONS_INFLIGHT_SYMS`
     * `is_options_inflight(sym)`
     * `claim_options_inflight(sym, scope)`
     * `release_options_inflight(sym, scope)`

2. Add future-based coalescing to TradierProvider option calls.

   * Add coalescing for `get_option_expirations(symbol)`.
   * Add coalescing for `get_option_chain(symbol, expiration)`.
   * If two coroutines request the same expiration or chain key simultaneously, only one Tradier request should fire; the others await/reuse the same future.
   * Track `coalesced_expiration_requests` and `coalesced_chain_requests`.

3. Standardize unavailable/no-options caching.

   * The theme supplement already has 24h no-options tracking.
   * Make portfolio/watchlist/shared options scan use the same concept or a compatible TTL.

   * Use 24h if confidently “no options,” or at least 30–60 minutes if merely “temporary unavailable/error.”
   * Return stale/unavailable metadata clearly.
