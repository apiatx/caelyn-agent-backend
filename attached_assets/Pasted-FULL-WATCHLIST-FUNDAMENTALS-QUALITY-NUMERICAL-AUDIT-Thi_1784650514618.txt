PART 4 — INDEPENDENT VALUATION RECOMPUTATION
==================================================

Independently calculate the following.

Do not simply copy FMP ratio fields.

Use one documented canonical price/market-cap timestamp for all valuation metrics.

### Trailing P/E

Primary independent formula:

current canonical market cap / strict TTM net income

Requirements:
- Exactly four distinct quarters
- TTM net income must be positive
- Same currency
- P/E <= 0 is N/M

Also compare against:

current price / TTM diluted EPS

Explain any difference caused by share-count changes.

Compare:
- Independent P/E
- FMP priceToEarningsRatioTTM
- Stored PE Ratio
- Watchlist API value
- Frontend value

### Trailing P/S

Formula:

current canonical market cap / strict TTM revenue

Compare:
- Independent P/S
- FMP priceToSalesRatioTTM
- Stored PS Ratio
- Frontend value

### Enterprise value

Calculate a clearly labeled simplified EV:

current canonical market cap
+ total debt
- cash and short-term investments

Also report whether FMP provides:
- preferred equity
- minority interest
- other EV adjustments

Compare the simplified EV with FMP’s enterprise value.

Do not silently use two different EV definitions across columns.

### EV/EBITDA

Formula:

canonical EV / strict TTM EBITDA

Requirements:
- Four complete quarters
- Positive EBITDA
- Positive meaningful EV
- Same currency

Compare against FMP evToEBITDATTM.

### Net Debt/EBITDA

Formula:

(total debt - cash and short-term investments) / strict TTM EBITDA

State whether negative values mean net cash and whether the frontend should show them.

### P/FCF

Formula:

current canonical market cap / strict TTM free cash flow

Requirements:
- Positive FCF
- Same currency
- Otherwise N/M

### FCF Yield

Formula:

strict TTM free cash flow / current canonical market cap × 100

Mandatory invariant:

FCF Yield % ≈ 100 / P/FCF

For every row containing both values, report the variance.

### Forward P/E

Formula:

current canonical share price / FY1 annual consensus EPS

Requirements:
- FY1 must be the correct next unreported fiscal year
- EPS must be for the same listing/share/ADR basis
- Positive EPS
- Same currency/share basis
- Record analyst count
- Record estimate period
- Record price timestamp

Compare against:
- Stored Forward P/E
- FMP estimate input
- Quarterly-EPS×4 fallback
- Any public/direct FMP forward metric available under the plan

Do not call a quarterly×4 approximation equivalent to FY1 annual consensus.

### Forward P/S

Formula:

current canonical market cap / FY1 consensus revenue

Requirements:
- Correct FY1 period
- Same currency
- Same company/listing basis
- Positive revenue

### Forward EV/Sales

Formula:

canonical EV / FY1 consensus revenue

### Forward EV/EBITDA

Formula:

canonical EV / positive FY1 consensus EBITDA

For every forward metric, print:

- completed actual FY date
- selected FY1 date
- number of fiscal years ahead
- raw consensus estimate
- analyst count
- numerator source
- numerator timestamp
- denominator source
- denominator period
- currency compatibility result
