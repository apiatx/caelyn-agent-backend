Fix ONLY the Watchlist toggle on the Earnings tab of the Calendar page.

Backend repo:
apiatx/caelyn-agent-backend

Critical context:
- The All toggle is working correctly. Do not change it.
- The All toggle uses a custom curated/thematic earnings calendar. That logic is separate and should remain untouched.
- The Watchlist toggle is currently wrong because it is still showing the same curated symbols as All.
- The Watchlist toggle must use the user’s actual saved Watchlist symbols from the Watchlist page.

Goal:
When the user clicks Watchlist on the Earnings tab of the Calendar page, the calendar should show upcoming earnings events only for tickers on the user’s saved/uploaded Watchlist page.

Expected behavior:
- All toggle:
  - Keep current curated/thematic earnings logic exactly as-is.
- Watchlist toggle:
  - Load the user’s saved Watchlist tickers from Neon / the same backend source used by the Watchlist page.
  - Scan those symbols for upcoming earnings events over the next 2 months.
  - Return all upcoming earnings events found for those watchlist symbols.
  - Display them in the same response shape/style that the All toggle calendar already uses.
  - If a watchlist symbol has no earnings event in the next 2 months, omit it.
  - Never show tickers that are not on the user’s Watchlist.

Hard rule:
The Watchlist toggle must NOT filter or reuse the All curated earnings dataset.
The Watchlist toggle must start from the saved Watchlist symbol list.
