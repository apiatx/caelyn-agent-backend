**Source date:** 2026-06-20 | **Curated by:** Phase-2 static map

## Context
Microsoft capex ~$80B FY2025 AI datacenter; customer demand above supply. Azure GB200 VMs (Nvidia), Azure MI300X VMs (AMD), Maia custom chips (TSMC). True stack: AI accelerators → TSMC/HBM → packaging → networking → power → storage → devices.
Directness: Confirmed=direct link; Reported=credible reporting; Upstream=critical to Microsoft's suppliers; Thematic=relevant layer.
